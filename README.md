# Booking bot + mini app

База теперь на Postgres, а не SQLite — сделано именно затем, чтобы не
нужен был Railway Volume (его через мобильный браузер почти невозможно
добавить — только через канву проекта, которая на телефоне не рисуется
как надо). Postgres добавляется обычной кнопкой, без этого танца.

## Перед первым запуском
1. **Если хочешь сохранить команды старого бота** — пришли мне его `bot.py`, я сам вставлю их в `main.py`.
2. Добавь Postgres в проект (шаги ниже) — без него сервис не запустится.

## Переменные окружения
| Переменная | Значение |
|---|---|
| `BOT_TOKEN` | токен твоего бота |
| `TRAINER_TG_ID` | твой Telegram id (узнать через `@userinfobot`) |
| `MINIAPP_URL` | публичный домен сервиса (см. ниже) |
| `DATABASE_URL` | НЕ вводишь руками — подтягивается кнопкой Reference из Postgres-сервиса (шаг 3 ниже) |
| `ANTHROPIC_API_KEY` | ключ с console.anthropic.com — отдельный от claude.ai, платится по использованию, нужен для фото-калорий |
| `TRAINER_TZ` | часовой пояс для напоминаний и сводки, по умолчанию `Europe/Minsk` |

## Деплой на Railway — без Volume, всё кнопками

1. В проекте, где лежит сервис бота — нажми **+ New**
2. Выбери **Database → Add PostgreSQL** (обычная кнопка, не канва)
3. Открой сервис бота → вкладка **Variables** → **+ New Variable** → рядом с полем есть **Add Reference** → выбери Postgres-сервис → `DATABASE_URL`. Переменная подтянется сама, значение вводить не нужно
4. Добавь остальные переменные из таблицы выше (`BOT_TOKEN`, `TRAINER_TG_ID`, `ANTHROPIC_API_KEY`) тем же способом, что и раньше — руками через VARIABLE_NAME / VALUE
5. **Settings → Networking → Generate Domain** → скопируй ссылку → добавь как `MINIAPP_URL`
6. **Deployments → Redeploy**

## Обновление кода дальше
Тот же цикл, что и раньше: скачал файлы → загрузил на GitHub (Add file → Upload files) → Railway передеплоит сам.

## Проверка после деплоя
- В Telegram открой бота → должна появиться кнопка меню «Запись»
- `/clients` — пусто, пока никто не открывал мини-эп
- Открой мини-эп с любого аккаунта → `/clients` должен показать этот id
- `/add_slot 2026-09-20 18:00 60 2` → слот должен появиться в мини-эпе
- `/set_program <id> текст программы` → в мини-эпе под этим id, вкладка «Моя программа», должен показать текст
- `/set_kbju <id> 2400 180 70 250`
- Забронировать слот → должно прийти уведомление тебе в бота с ростером
- Пришли боту фото еды → должна прийти оценка калорий и БЖУ, плюс сумма за день
- `/set_weight 78` → затем `/activity бег 30` → должен посчитать сожжённые калории
- `/log_lift жим 80 8 4` (от имени клиента) → `/progress <id> жим` (от тебя) → должен прийти график
- Пришли боту видео с подписью-упражнением (от клиента) → тебе придёт то же видео с контекстом → ответь на него текстом (можно начать с 1-10 — это оценка) → клиенту придёт разбор
- `/pending_reviews` — список видео, которые ещё не разобраны
- Напоминания и воскресная сводка работают в фоне сами — если через сутки не пришло напоминание, смотри `railway logs` на ошибки
